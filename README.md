# 🌦️ Weather Pattern Visualization Dashboard

## 📌 Overview

Weather plays an important role in our daily lives, influencing transportation, agriculture, tourism, and many other sectors. This project focuses on analyzing weather data and presenting meaningful insights through an interactive Power BI dashboard.

The dashboard transforms raw weather records into easy-to-understand visualizations, helping users identify trends in temperature, rainfall, humidity, and other weather conditions over time.

---

## 🎯 Project Objectives

- Analyze historical weather data.
- Identify seasonal and monthly weather patterns.
- Visualize temperature, rainfall, humidity, and wind speed trends.
- Compare different weather conditions across time.
- Create an interactive dashboard for better decision-making.

## 🧹 Data Preparation

Before building the dashboard, the dataset was cleaned using Power Query.

The following preprocessing steps were performed:

- Removed duplicate records
- Handled missing values
- Corrected data types
- Renamed columns
- Trimmed unnecessary spaces
- Extracted Month and Year from Date
- Verified numerical columns
- Prepared data for visualization

---

## 📊 Dashboard Features

The dashboard includes multiple interactive visualizations:

### 🌡️ Temperature Trend
Displays how temperature changes over time.

### 🌧️ Monthly Rainfall Analysis
Shows rainfall distribution across different months.

### 💧 Humidity Analysis
Visualizes average humidity levels.

### 🌬️ Wind Speed Trend
Tracks changes in wind speed over time.

### ☀️ Weather Condition Distribution
Displays the proportion of Sunny, Rainy, Cloudy, and other weather conditions.

### 📈 KPI Cards

- Average Temperature
- Maximum Temperature
- Total Rainfall
- Average Humidity

### 🎛 Interactive Filters

- Year
- Month
- Weather Condition
